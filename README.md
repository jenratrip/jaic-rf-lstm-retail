# Retail Demand Forecasting using Random Forest and LSTM
This repository contains the research notebook, experimental results, and figures for a retail demand forecasting study using Random Forest (RF) and Long Short-Term Memory (LSTM).
The study evaluates forecasting performance using a time-based holdout split and rolling-origin evaluation, with a focus on strict feature selection to prevent data leakage.

## Dataset
The dataset used in this study is the **Retail Pricing and Demand Signals Dataset**, available on Kaggle:
https://www.kaggle.com/datasets/noopurbhatt/retail-pricing-and-demand-signals-dataset
Download the dataset and place the CSV file in the repository root directory, alongside the Jupyter Notebook.

The expected filename is:
`retail_pricing_demand_100k.csv`
The raw dataset is not included in this repository.

## How to Run
1. Clone or download this repository.
2. Download the dataset from Kaggle.
3. Place `retail_pricing_demand_100k.csv` in the repository root directory.
4. Install the required Python dependencies.
5. Open `jaic_revision_retraining_v3_clean.ipynb` using Jupyter Notebook, JupyterLab, or Google Colab.
6. Run the notebook sequentially from Section 0 to Section 8.


### Notebook Sections
| Section | Description |
|---|---|
| 0 | Setup and Configuration |
| 1 | Data Preprocessing and Feature Engineering |
| 2 | Random Forest |
| 3 | LSTM |
| 4 | Comparison Models (Optional) |
| 5 | Evaluation |
| 6 | Restock Recommendation |
| 7 | Visualization |
| 8 | Export Results |
The notebook automatically creates the `data/`, `results/`, and `figures/` directories when executed.


## Experimental Configuration
The main experimental configuration is as follows:
| Parameter | Value |
|---|---|
| Random seed | 42 |
| LSTM seeds | 42, 43, 44 |
| Train-test split | 80:20 (time-based) |
| Feature set | Strict |
| Fast mode | False |
| Comparison mode | None |
| Rolling-origin folds | 5 |
| Rolling block size | 7 days |
| Maximum LSTM epochs | 100 |
| LSTM early stopping patience | 15 |

The strict feature set uses information available before the prediction time to reduce potential data leakage.


## Experimental Results
The `results/` directory contains the experimental outputs, including:
- Holdout and rolling-origin evaluation metrics.
- Statistical significance analysis.
- Random Forest and LSTM prediction outputs.
- Feature importance and ablation results.
- Restock recommendation and inventory simulation results.
- Experimental configuration and hyperparameter summaries.
The `figures/` directory contains the visualizations generated by the notebook, including the rolling-origin comparison between Random Forest and LSTM across different LSTM seeds.


## Reproducibility
The notebook is provided to support the reproduction of the experimental workflow. The raw dataset must be downloaded separately from Kaggle before execution.
The recorded experimental configuration is available in:
`results/config_and_hyperparameters.json`
The prediction files, evaluation tables, metadata, and figures are provided to support inspection and comparison of the reported results.
